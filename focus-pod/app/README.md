# iPhone app

The pod is "dumb": it only holds an NFC tag. The blocking is done by a custom fork of [Foqos](https://github.com/awaseem/foqos), an open-source iOS app that uses Apple's Screen Time API and can use an NFC tag to start and stop blocking.

- Link to the fork here once it exists. Don't copy its source into this repo.
- Foqos is MIT-licensed: keep its copyright notice in the fork and credit it here.
- Tags: NTAG213/215/216 all work with iPhone Core NFC.
